### A-1：信息架构 6→4（P1）⚠️ 完成后经 v0.10.1 调整为 3 Tab

**核实结论**：spec 原文为 4 Tab（数据/报告/语义/SQL 历史）；当前 main 实际为 **3 Tab**——"语义"不是缺失，而是在 v0.10.1 有记录地**并入数据 Tab**：

| 证据点 | 内容 |
|--------|------|
| `index.html:29` | 注释明示："v0.10.1: 数据 + 语义合并为一个工作台 Tab（3 Tab：数据 / 报告 / SQL 历史）" |
| `index.html:23-25` | 静态导航仅 3 个 nav-item：`data` / `reports` / `sql-history` |
| `app.js:309` | `VALID_TABS = ["data", "reports", "sql-history"]`，无动态注入第 4 个 Tab 的代码（grep semantic/语义/registerTab 均无动态建 Tab 逻辑） |
| `index.html:51-95` | 语义内容全部保留在 `#tab-data` 内的 4 个 `semantics-section` 区块：**数据体检 / 表卡片 / 字段字典 / 指标定义** |
| `app.js:8/18`（文件头注释） | "数据工作台（原'数据'+'语义'合并）"、"数据 + 语义 → 一个工作台 Tab；上传改弹窗" |

**判定理由**：旧 6 Tab 的内容（上传、预览、口径、字典等）在新结构中全部可达，语义四区块一应俱全，功能等价性成立；导航项数量与 spec 原文（4）不一致系后续版本有意合并（v0.10.1 注释可查），非遗漏。故记 **完成（带偏差说明）**。
