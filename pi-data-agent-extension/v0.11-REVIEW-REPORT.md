## 与 spec 的偏差说明

1. **F-1 nav-context 修复成本**：spec §12.2 允许"工作量过大记入 BACKLOG"，实测修复量小（截断逻辑局部调整），按修复处置，未进 BACKLOG
2. **maxQueryMemoryEntries 处置路径**：spec 给"生效或移除"二选一，选择让配置实际生效（构造函数加参数 + index.ts 传入，改动小且保留用户可配置语义）
3. **requirements.txt 版本钉死冲突**（计划外发现）：原钉死版本组合 pip 解析失败，测试环境暂以不锁版本安装绕过；版本矩阵重新固化已记入 BACKLOG
4. **config.ts DEFAULTS 路径固化**（计划外发现）：`projectConfigDir`/`dbPath` 在模块加载时固化为绝对路径，`loadConfig({cwd})` 覆盖不隔离这些目录；不影响单实例生产语义，但影响测试隔离，已记入 BACKLOG（不属本版范围）
5. **T-1 迁移保留白名单项**：无。所有测试均完成迁移，exclude 仅剩 fixtures 数据目录
