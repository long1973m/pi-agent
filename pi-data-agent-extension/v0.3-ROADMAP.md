# v0.3 建议规划

> 日期：2026-07-02
> 基于 v0.2 已知问题 + 用户反馈 + Spec 未完成项

---

## 优先级 P0（必须完成）

### 1. Pi CLI 真实交互验证

- 4.2.5 完整 Agent 交互链：用户说"分析一下这些数据" → 反问 → 选择 → 查询
- 4.2.7 完整口径复用：用户再次问同一问题 → 直接应用口径
- 5 个金标准任务端到端验证（T1-T5）

### 2. 性能基准测试

- 大数据集（10万+行）load/query/visualize 响应时间
- 多表场景（10+张表）fingerprint 计算和召回效率
- 长会话（50+ 次查询）内存和查询记忆稳定性

---

## 优先级 P1（建议完成）

### 3. 数据字典用户确认

- `ensureDictionary` 生成字典后调用 `ctx.ui.confirm()`
- 用户可选择：确认 / 修正字段语义 / 标记为不需要字典
- 状态流转：ai-guessed → validated / user-corrected

### 4. 查询记忆公式对齐

- 淘汰公式改为 `log(useCount+1) × exp(-(now-lastUsedAt)/7天) × relevanceScore`
- `QueryMemoryEntry` 增加 `relevanceScore` 和 `lastUsedAt` 字段

### 5. connect_database 扩展

- 支持 PostgreSQL（通过 DuckDB postgres_scanner 扩展）
- 支持 MySQL（通过 DuckDB mysql_scanner 扩展）
- 连接信息脱敏（不在 audit log 中暴露密码）

### 6. LLM 增强数据字典

- 替换列名模式推断为 LLM 推断（调用 Pi LLM API）
- 支持中文列名语义推断
- 支持业务术语映射
